# AI application with hugging face
## Description
This repository is created for collecting course material and show of using AI in hugging face, and also have mini project in this course such as Chatbot

## How to install
```
git clone https://github.com/PhoengZ/AI-App-with-hugging-face.git
cd AI-App-with-hugging-face
```

## Usage 
1. If you want to learn intro to neural network with hugging face, all material is inside 'NLP' folder
2. If you want to learn application of ai model, all material is inside 'NLP' folder
3. If you want to watch Seminar homework, all assignment is inside 'CUVIP' folder
4. If you want to watch Mini project 'Chatbot', the file is inside 'Chatbot' folder
5. If you want to watch Mini project 'Menu maker', the file is inside 'Menu-maker' folder

## Tech stack and tools
1. Python
2. Google colab (or Jupyter notebook)
